## 📌 Tentang Proyek

Repository ini merupakan tempat penyimpanan dan pengembangan proyek website yang dibuat sebagai bagian dari proses pembelajaran di bidang Pengembangan Perangkat Lunak dan Gim (PPLG).

Proyek ini dikembangkan untuk meningkatkan pemahaman mengenai pengembangan website, struktur HTML, desain CSS, serta penerapan JavaScript.

## 🎯 Tujuan

- Meningkatkan keterampilan dalam pemrograman web.
- Memahami struktur dan fungsi HTML, CSS, dan JavaScript.
- Mengembangkan kreativitas dalam merancang website.
- Menerapkan ilmu yang diperoleh selama proses pembelajaran.

## 🛠️ Teknologi yang Digunakan

- HTML — menyusun struktur halaman website.
- CSS — mengatur tampilan dan desain website.
- JavaScript — menambahkan interaktivitas pada website.

## 🚀 Pengembangan

Proyek ini akan terus dikembangkan secara bertahap untuk meningkatkan kualitas desain, fungsionalitas, dan pengalaman pengguna.
